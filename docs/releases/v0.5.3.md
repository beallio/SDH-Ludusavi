# v0.5.3 — Stock CSS Loader themes reload again

Patch release. Save checks, backups, and restores work exactly as they did in v0.5.2, and this release fixes theme reloading for people on the stock CSS Loader.

## Fixed

- **The stock DeckThemes CSS Loader reloads updated themes again.** Since v0.5.1, if you ran the stock DeckThemes CSS Loader with the SDH-Ludusavi status-bar theme, an update could leave you with the message "CSS Loader could not reload the updated theme", and the status-bar theme was not reloaded. The plugin now falls back to Decky's older plugin call route, and only after Decky rejects the newer call with that exact reported cause. Any other failure is reported exactly as before, so real problems are not hidden. Checked on a Steam Deck virtual machine with the stock CSS Loader 2.1.4: v0.5.2 showed the warning and reloaded nothing, while this release showed no warning and CSS Loader reloaded its themes.

## Added

- **The Decky Loader fork's own debug setting now turns on the plugin's debug log.** If your Decky Loader fork has the plugin's debug option enabled (decky-loader v3.3.1-rust.1-rc.3 and later), SDH-Ludusavi now writes its detailed debug lines even when the plugin's own debug setting is off. Nothing changes if you had both off, and nothing changes on standard Decky Loader.

## Internal

- The decky-plugin SDK was updated to the current decky-loader build, 192cedc, which is what lets the loader's debug setting reach the plugin.

## Install

Download `SDH-Ludusavi-v0.5.3.zip` below and install it through Decky Loader. Verify the download against `SDH-Ludusavi-v0.5.3.zip.sha256`:

```bash
sha256sum -c SDH-Ludusavi-v0.5.3.zip.sha256
```

If you already have SDH-Ludusavi installed, updating keeps your settings, your save history, and your Ludusavi backups in place.
