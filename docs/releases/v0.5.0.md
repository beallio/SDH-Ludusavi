# v0.5.0 — A new backend for save management

SDH-Ludusavi now uses a native program to manage its save checks, backups, and restores. You can use the same plugin package with standard Decky Loader or the Decky fork that starts native plugins directly.

Your existing plugin settings and save history are kept when you update. Your Ludusavi backups stay where they are. You still need Ludusavi installed and configured to create or restore backups.

The download is smaller, the plugin does less background work while idle, and game lists refresh faster when you request a refresh.

The new backend has passed automated checks, including tests using Ludusavi itself. It has not yet been installed and exercised on a real Steam Deck or virtual machine under either loader. Updating a running backend through standard Decky, and shutdown behavior in the presence of a known Decky issue, also remain unverified on a real device.
