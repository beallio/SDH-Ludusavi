# v0.5.0 — A new backend for save management

SDH-Ludusavi now uses a native program to manage its save checks, backups, and restores. You can use the same plugin package with standard Decky Loader or the Decky fork that starts native plugins directly.

Ludusavi now comes with the plugin, so you no longer need to install it from Discover. The Ludusavi shortcut in the plugin opens the included copy, where you choose your backup folder. If the included copy cannot start, the plugin uses the Ludusavi Flatpak instead, if you have it installed.

Your existing plugin settings and save history are kept when you update, and your Ludusavi backups stay where they are. The first time the plugin starts the included Ludusavi, it copies your existing Ludusavi settings and game list from the Flatpak, so you do not need to set anything up again. It never replaces settings that are already there.

Save checks are faster. In testing on a Steam Deck, each check took about 0.4 seconds instead of about 1.1 seconds. The plugin also does less background work while idle, and game lists refresh faster when you request a refresh. Because Ludusavi is included, the download is larger than before.

The new backend has passed automated checks, including tests using Ludusavi itself. It has not yet been installed and exercised on a real Steam Deck or virtual machine under either loader. The included Ludusavi window has not yet been tried in Gaming Mode on a real Deck. Updating a running backend through standard Decky, and shutdown behavior in the presence of a known Decky issue, also remain unverified on a real device.
