# v0.4.9 — Choose how save status bars look

If you use CSS Loader, you can now change the look of both the Steam Cloud and Ludusavi save status bars on game pages. Keep their original look, choose a clean dark bar, or pick your own background, text, icon, and outline colors. The game's picture can show through a transparent bar, even when no trailer is playing. The bars stay in their usual place.

The theme is installed with the plugin. In CSS Loader, open **SDH-Ludusavi Status** and use the **Save Status** slider to choose **Default**, **Clean View**, or **Custom**. Custom color pickers include transparency, and a separate slider sets the outline width. If the theme does not appear after installation, use **Refresh** in CSS Loader.

These choices change appearance only. They do not change save checks, backups, or Steam Cloud controls. Your choices stay in place when you update the plugin, and they remain available if you reinstall it later.

## Known limits

- CSS Loader is optional. Without it, the save status bars keep their original look.
- The separate status strip shown during game launch is not themed.
- There is no icon-only option; both bars keep their labels.
- Warning, error, and active colors keep their normal meaning. This was checked without starting a real Cloud transfer or save conflict.
