# v0.4.9 — Choose how save status bars look

If you use CSS Loader, you can now change the look of both the Steam Cloud and Ludusavi save status bars on game pages. Keep their original look, choose a clean dark bar, or pick your own background, text, icon, and outline colors. The game's picture can show through a transparent bar, even when no trailer is playing. The bars stay in their usual place.

The theme is installed with the plugin. In CSS Loader, open **SDH-Ludusavi Status** and use the **Save Status** slider to choose **Default**, **Clean View**, or **Custom**. Custom color pickers include transparency, and a separate slider sets the outline width. When theme files change during installation or an update, the plugin asks CSS Loader to reload them. If the new look does not appear, use **Refresh** in CSS Loader.

Clean View no longer adds a thin line above the save-status bars. Steam's short lines beside the status text remain.

On games without a save-status bar, the theme now leaves a blank strip below the play controls before Activity. Clean View and Custom give the strip the same background as their status bars; Custom also uses your outline choice. With Clean Gameview, the game's picture or trailer can show through the strip instead of a dark patch. The empty strip does not report a backup.

The theme changes appearance and spacing only. It does not change save checks, backups, or Steam Cloud controls. Your choices stay in place when you update the plugin, and they remain available if you reinstall it later.

## Known limits

- CSS Loader is optional. Without it, the save status bars keep their original look.
- The separate status strip shown during game launch is not themed.
- There is no icon-only option; both bars keep their labels.
- Warning, error, and active colors keep their normal meaning. This was checked without starting a real Cloud transfer or save conflict.
- On an uninstalled game, the extra spacing may put Activity below the bottom menu until you scroll down.
