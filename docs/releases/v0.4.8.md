# v0.4.8 — Save status on the game details page

SDH-Ludusavi can now show the latest save result directly on eligible non-Steam game
details pages. The new read-only row uses the same compact visual style as Steam's Cloud
status, while the separate launch strip continues to protect work that happens before a
game starts.

## What changed for you

**See the latest result without opening Decky.** The game details page can now show whether
Ludusavi is checking, backing up, restoring, up to date, out of sync, or unable to sync.
The row does not add another controller stop or an action that you can select.

**The row matches Steam's status presentation.** It uses short centered labels, balanced
lines, Steam-blue activity text, and a pulse while work is active. Warnings and failures
remain visually distinct.

**A result keeps the same meaning after a reload.** A save that is already current now
continues to read **Up to date** after the plugin reloads. An unclassified result uses the
normal row style instead of looking like a warning.

**Local and remote results stay separate.** A successful local backup is not presented as
proof that another Syncthing device received it. The row reports remote progress only when
the plugin observed it.

**Steam Cloud pages stay unchanged.** If Steam already provides its own Cloud status band,
SDH-Ludusavi does not replace it or add a second band. This display choice does not change
backup or restore eligibility.

## Known limits

- If the plugin restarts while you keep the same game details page open, the Ludusavi row
  may not return. Open another page, then return to the game details page.
- In some game details layouts, the row can reserve its place but remain hidden. This is
  separate from the restart problem above.

These are display problems. They do not change whether backup or restore work runs, and the
launch strip remains available for protected work before a game starts.
