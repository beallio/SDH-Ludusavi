# v0.4.8 — Save status on the game details page

See your latest Ludusavi save result directly on supported non-Steam game pages. The new
row matches Steam's Cloud status style and shows clear messages such as **Backing up**,
**Restoring**, and **Up to date**.

![Ludusavi showing Up to date on a non-Steam game details page](https://raw.githubusercontent.com/beallio/SDH-Ludusavi/v0.4.8/assets/native-status-row.webp)

Steam Cloud pages stay unchanged, and the launch strip still protects save checks before a
game starts.

## Known limits

- If the plugin restarts while this page stays open, open another page and return to restore
  the row.
- On some layouts, the row may leave an empty space instead of appearing. Backup and restore
  still work.
