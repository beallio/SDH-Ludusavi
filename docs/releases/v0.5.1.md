# v0.5.1 — Theme reload fix and quieter logs

Patch release. Save checks, backups, and restores work exactly as they did in v0.5.0.

## Fixed

- **No more false "CSS Loader could not reload the updated theme" warning.** If you use CSS Loader with the SDH-Ludusavi status bar theme, the plugin used to report that warning at startup even when CSS Loader had already reloaded the theme. The reload request now goes through the Decky plugin call that both standard Decky Loader and the native-backend Decky fork accept, so the warning only appears when the request really fails. CSS Loader also reports which themes failed to load, and the plugin now warns when the SDH-Ludusavi status theme is one of them, even if the request itself succeeded.
- **Games you do not track no longer fill the log with warnings.** Steam tells the plugin about every app that starts and quits, including games that are not in your Ludusavi game list. Those events used to write a warning each time, once when the game started and once when it quit. They now appear only in the debug log. If a game you *do* track cannot be identified, that warning is still written, because it means the plugin could not tell which game to back up.

## Security

- The archive reader the plugin uses to count the files inside your backups was updated to a current version. The older version had known flaws that a deliberately malformed backup file could trigger. Backups are only read from your own backup folder, so this was not remotely reachable, but the update removes the exposure entirely.

## Install

Download `SDH-Ludusavi-v0.5.1.zip` below and install it through Decky Loader. Verify the download against `SDH-Ludusavi-v0.5.1.zip.sha256`:

```bash
sha256sum -c SDH-Ludusavi-v0.5.1.zip.sha256
```

If you already have SDH-Ludusavi installed, updating keeps your settings, your save history, and your Ludusavi backups in place.
