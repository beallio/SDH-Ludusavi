# v0.5.2 — Quitting a game now runs its save check

Patch release. Save checks, backups, and restores work the same way as they did in v0.5.1, and this release fixes a bug that could skip the check when you quit a game.

## Fixed

- **Quitting a game again runs the exit save check.** Since v0.5.0, some games did not get their automatic save check when you quit them. Steam can note a game's start and its exit under different internal labels, and the plugin only matched exits by the label it recorded at start. When the labels did not match, the plugin ignored the exit, so no check ran and no backup was made. The plugin now matches the exit to the game it knows is running, so the check runs as it should. If a quit event still cannot be matched, the plugin only warns when the app is one you track or one that was actually running.

## Install

Download `SDH-Ludusavi-v0.5.2.zip` below and install it through Decky Loader. Verify the download against `SDH-Ludusavi-v0.5.2.zip.sha256`:

```bash
sha256sum -c SDH-Ludusavi-v0.5.2.zip.sha256
```

If you already have SDH-Ludusavi installed, updating keeps your settings, your save history, and your Ludusavi backups in place.
