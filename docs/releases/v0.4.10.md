# v0.4.10 — Keep game artwork steady as the page opens

With Clean Gameview and the SDH-Ludusavi Status theme enabled, the game's picture now starts at the height needed to cover the save-status bar. It no longer changes its crop again when that bar appears. Steam's normal page animation still plays, and the Play controls and Activity stay in place.

The same space is kept when the bar shows Steam Cloud, shows Ludusavi, or is blank. This changes appearance only; it does not change save checks, backups, or Steam Cloud controls.

## Known limits

- This early height reservation needs CSS Loader, Clean Gameview, and the enabled SDH-Ludusavi Status theme. Without them, the plugin still extends artwork after it detects a visible status bar.
- Use the matching Decky Metadata development update to prevent its trailer from shrinking and growing during the page animation.
- Themes that move or hide the status bar, clip the artwork, or set a competing artwork height can still conflict. Color-only status themes are not affected by the sizing calculation, but their colors still follow CSS Loader's normal theme priority.
