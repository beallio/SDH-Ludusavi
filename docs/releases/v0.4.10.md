# v0.4.10 — Native status styling and steadier game artwork

The Ludusavi save-status bar now follows Steam's status-bar layout and styles. CSS Loader themes that change the Steam Cloud bar can also change the Ludusavi bar. Steam Cloud keeps its own controls and status.

With Clean Gameview and the SDH-Ludusavi Status theme enabled, the game's picture starts at the height needed to cover the save-status bar. It no longer changes its crop again when the bar appears or a trailer starts. The extra size change also stays gone after turning these themes off and on. Steam's normal page animation still plays, and the Play controls and Activity stay in place.

The picture follows a full-width bar's actual height. Taller bars get more picture space; compact, moved, or hidden indicators do not add full-width space. A blank row can still show the picture or trailer behind it. This changes appearance only, not save checks, backups, or Steam Cloud controls.

After a game closes, its own page now shows the full save message. You can tell whether the plugin is checking, making the local backup, preparing or sending the shared backup, or warning that the remote copy is not confirmed. If you leave that game page, the post-game message disappears but the work continues. Return to the page to see the newest state or final result. If a theme hides, covers, clips, or cannot fit the normal row, the fallback message appears only on that same page. Home and other games stay quiet, and their normal status rows still work.

This does not change save work, failure notifications, Steam Cloud controls, or launch protection. A local backup still does not prove every other device has received it. After a plugin reload, earlier remote activity can still be unverified until a new observation.

## Known limits

- Early height reservation needs CSS Loader, Clean Gameview, and the enabled SDH-Ludusavi Status theme. Without them, the plugin still extends artwork after it detects a visible status bar.
- Use the matching Decky Metadata development update for the trailer-height correction.
- Themes that clip the artwork or set a competing artwork height can still conflict. Colors still follow CSS Loader's normal theme priority.
- Full post-game messages were checked on a Steam Deck with test statuses and automated layout checks. Other third-party themes still need their own live check; when the native row cannot show the whole message, the same-page fallback is used instead.
- Live checks covered Steam Cloud and Ludusavi game-page display, theme changes, and trailer sizing. Actual backup, restore, conflict, and network-transfer operations were not part of this display check.
