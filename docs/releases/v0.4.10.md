# v0.4.10 — HLTB game times restored

## Changes since the previous development build

- HLTB's game times appear again on game pages with SDH-Ludusavi enabled. PlayTime's play-time display and Ludusavi's save-status row continue to work.
- If a game's page was open during the update, press **B** to return to Home or your library, then open that game's page again. The updated display loads on the next visit. You do not need to launch a game or restart Steam, and the plugin does not force the open page to redraw.

## Also included

- After you quit a game, readable save progress stays in the normal status row. Transparent footer padding no longer makes it switch to a separate message. Menus, covering paint, and cut-off text still use the fallback, and the normal row returns when the obstruction clears.
- When the post-game fallback is needed, its font, spacing, colors, and animation now match Steam's status row.
- Save checks, local backup, restore, upload preparation, and disabled saves have clearer icons. Completed saves use Steam's normal completed-cloud shape, while warnings remain distinct.
- The picture, Play area, and status row keep their original positions and artwork crop. The separate game-launch message keeps its existing appearance and protection.

The Ludusavi save-status bar now follows Steam's normal status-bar layout and style by default. Its icons still tell local backup, shared-backup activity, completion, warnings, errors, and disabled saves apart, but they now fit the Steam row's normal size and alignment. CSS Loader themes that change the Steam Cloud bar can still change the Ludusavi bar. Steam Cloud keeps its own controls and status.

The game page keeps its original layout. The Play area and status row do not move to make extra room, and the picture does not get a new height or crop when the row appears. Steam's normal page animation still plays.

A blank status row can still show the picture or trailer behind it. This changes appearance only, not save checks, backups, or Steam Cloud controls.

Not tracked and Unknown use a simple question mark inside a circle. The icon keeps the normal size, and the message keeps the same meaning.

After a game closes, its own page now shows the full save message. You can tell whether the plugin is checking, making the local backup, preparing or sending the shared backup, or warning that the remote copy is not confirmed. If you leave that game page, the post-game message disappears but the work continues. Return to the page to see the newest state or final result. If a theme hides, covers, clips, or cannot fit the normal row, the fallback message appears only on that same page. Home and other games stay quiet, and their normal status rows still work.

This does not change save work, failure notifications, Steam Cloud controls, or launch protection. A local backup still does not prove every other device has received it. After a plugin reload, earlier remote activity can still be unverified until a new observation.

## Known limits

- The default layout keeps Steam's own appearance. Clean View and Custom remain optional and keep their saved CSS Loader choices.
- The restored placement, clearer icons, and readable-message handling were checked on a Steam Deck with the current Clean Gameview and CSS Loader setup. Other theme choices can still cover or clip the normal row; in that case, the same-page fallback is used.
- Artwork behind a blank row needs CSS Loader, Clean Gameview, and the enabled SDH-Ludusavi Status theme. The plugin does not change the page layout when that theme support is absent.
- Themes that clip the artwork or set a competing artwork height can still conflict. Colors still follow CSS Loader's normal theme priority.
- Full post-game messages were checked on a Steam Deck with test statuses and automated layout checks. Other third-party themes still need their own live check; when the native row cannot show the whole message, the same-page fallback is used instead.
- Live checks covered HLTB times, PlayTime values, Steam Cloud and Ludusavi game-page display, theme changes, and trailer sizing. Actual backup, restore, conflict, and network-transfer operations were not part of these display checks.
